# UI 通用约束

> 跨项目共享，所有涉及 UI 开发的需求必须遵循。

## 设计规范先行

- **触发**: 任何涉及页面、组件、布局、配色、字体、交互的变更
- **约束**: 必须先查阅项目已有的设计规范和组件库，确认可复用后才能开始设计
- **禁止**: AI 自由创造与项目风格不匹配的 UI

## 组件复用优先

- 先查项目组件库清单，确认没有现成组件后再新建
- 新建组件必须走项目已有组件的接口风格（props 命名、样式传递方式）
- 禁止引入与已有组件功能重叠的新组件

## 暗黑模式全覆盖

- 所有新增 UI 必须同时在亮色和暗色模式下可用
- 禁止硬编码颜色值，必须使用 CSS 变量或主题令牌
- 暗黑模式下文字对比度不低于 4.5:1

## 响应式三断点

- 移动端 320px、平板 768px、桌面 1024px 三档必须覆盖
- 禁止出现横向滚动条
- 禁止 fixed 定位遮挡主要内容

## 动效约束

- 过渡动画 150-300ms，使用 ease-out
- 禁止布局位移类动画（width/height/top/left 过渡）
- 必须响应 `prefers-reduced-motion: reduce`，关闭非必要动效

## 可访问性底线

- 可交互元素必须有 visible focus ring
- 图标按钮必须有 aria-label
- form 输入必须有 label 关联

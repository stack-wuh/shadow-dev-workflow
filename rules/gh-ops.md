# GH 操作铁律

> 适用所有阶段（commit merge issue push），GH 操作最多执行 1 次，失败后立即停止输出手动命令。

## 决策树

```
执行 gh 操作
    │
    ├── 成功 ✓ ──► 继续下一步
    └── 失败 ──► 展示错误 + 手动命令 + PR 预览 → 停止

⛔ 不做：
  - 重复重试（同一命令最多 1 次）
  - 切换网络模式（SSH→HTTPS、代理 on/off）
  - curl API 回退
  - 休眠等待
  - gh pr merge（用户手动操作）
```

## 执行前检查

1. `git push --dry-run 2>&1` — 失败输出手动命令
2. `gh auth status 2>/dev/null` — 失败禁止所有 gh 操作

## 失败输出模板

```
## GitHub 操作失败: <操作名>
**错误:** <error>

### 手动执行
```bash
<完整可执行命令>
```

### <操作名> 预览
**标题:** ...
**描述:** ...
```

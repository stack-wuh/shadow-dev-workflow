# 补充铁律

> 在项目指令文件（CLAUDE.md / AGENTS.md）已有规则基础上，非协商，违反即阻断。

## 1. 不要跳过与复杂度匹配的验证

- **防什么**：实现偏离需求、回归不可检测
- **触发**：任何代码/行为变更
- **做什么**：按 brief 复杂度评级的验证强度执行（`norms/verification.md` 三层职责）：**L**——brief「## 领域模型」段每条 `INV-n` 一个可追溯观察点（真实命令 + 真实输出，覆盖拒绝路径与状态不变量）；**M**——冒烟 + 每条被触及不变量一个观察点 + 走查；**S**——执行结构、引用、残留扫描。（2026-10-09 取消先红仪式；20261010 验收对象＝领域不变量；2026-10-12 裁定「结合起来用」：规格层不变，门槛层恢复机器判定，先红后绿降格为 L 级可选取证策略 assert-first。强度与评级匹配仍不可议。）评级与取证策略在 propose 确认时批准；实现期风险升/降级先修订 brief 再继续。
- **放行判据（三条缺一不得 release）**：① 观察点闭合（`node scripts/check-brief.mjs`）；② guard 探针绿；③ regression 探针在其 CI 实测耗时 ≤ 60s 的仓里绿。
- **阻断**：验证强度与评级不符视为未开始；以「套件全绿」代替不变量观察点同样违规（绿是门槛，不是证据）；反之拿「CI 绿灯链接」单独充当 L 级观察点也违规。regression 探针跑不动只能记证据缺口，不得静默免除。

## 2. 不要声称完成而未验证

- **防什么**：假完成——声称修好了但实际没修好或引入新问题
- **触发**：声称 "done" "fixed" "完成" "OK" 之前
- **做什么**：跑 Lint + 类型检查 + 与本次不变量相关的探针或真实命令，贴出验证命令和输出；探针红必须归因
- **阻断**：无验证输出的完成声明一律视为无效

## 3. 不要猜测式修复 Bug

- **防什么**：随机改代码掩盖症状、反复试错浪费时间
- **触发**：遇到任何 Bug、异常、测试失败、意外行为
- **做什么**：系统化追溯根因，理解为什么出错再修（shadow-dev-review 会检查根因分析是否完整）
- **阻断**：未执行根因分析就改代码的修复，review 阶段直接驳回

## 4. 不要直接在 main 上提交代码

- **防什么**：污染主干、跳过 review、无法回滚
- **触发**：任何代码修改操作
- **做什么**：apply 阶段先创建功能分支再写代码；main 只接受 merge/PR 合入
- **阻断**：在 main 分支上的 commit 直接驳回

## 5. 不要重复尝试 GH 操作

- **防什么**：反复尝试 publish / PR / issue 网络操作，每次失败换一种方式重试
- **触发**：任何 GH 网络操作（push/PR/merge/issue）
- **做什么**：最多执行 1 次；失败后立即停止，输出手动命令，等待用户操作
- **阻断**：同一命令执行超过 1 次视为违规

## 6. 不要绕过 deterministic CLI

- **防什么**：brief、INDEX、Git 与 GitHub 状态分裂，或绕过确认和计划校验
- **触发**：任何 brief/INDEX 写入、Git 写操作或 GitHub API 写操作
- **做什么**：统一通过 `shadow-dev` 的 plan/execute 命令；execute 必须携带 planHash 和 `--confirm`
- **阻断**：禁止原始 `git`/`gh` 写命令、直接修改 brief frontmatter/INDEX、`git add .`、`git add -A`、`--no-verify`

## 7. 不要在缺少领域模型的情况下开始 L 级实现

- **防什么**：取消先红仪式后规格悬空——没有不变量，验收退化成 diff 走查，改坏了没人说得清
- **触发**：brief 复杂度评级为 L 的实现开始前
- **做什么**：brief 必含「## 领域模型」段（限界上下文 / 统一语言增量 / **非空**聚合与不变量清单 / 领域事件），格式与必填规则见 `norms/domain-model.md`；每条不变量以 `INV-n` 编号，在「结果」段有一行可追溯观察点，或明确标注证据缺口；L 级另须在「复杂度评级」节声明 `取证策略: assert-first|observation`。机器判定：`node scripts/check-brief.mjs`
- **阻断**：L 级 brief 缺该段、不变量清单为空、条目缺 `INV-n` 编号、或对账未闭合，`check-brief` 即判红且 release 阻塞；实现期发现新不变量时先修订 brief 再继续，不得静默扩面

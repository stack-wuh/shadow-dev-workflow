# Shadow Dev Design — UI 设计大师（布局与交互提案）

视觉与交互决策不靠嘴聊，靠**真 token 高保真视觉稿 + 多构提案 + 小步精修轮**收敛。本技能是 `shadow-dev-propose` 的设计伴侣：propose 负责需求对齐与 Knowledge 查询，本技能在「澄清需求」与「比较方案」之间插入视觉提案轮，产出的设计决策清单由 propose 写入 brief 决策段。也可独立调用，单纯打磨某处布局交互。

**执行纪律：** 视觉稿是本地产物，不写仓库与 GitHub；浏览器自动化只读操作。仓库写操作仍按主流程纪律（经 CLI 或随 change 提交）。

**进场：** 任何操作前，先输出：`▶ [进场] shadow-dev-design · UI 设计提案与打磨`

## 流程

### 1. 约束输入——视觉稿必须用真值

- 从项目源码提取**真实设计令牌**：调色板 hex（如 generator-color）、字体三 token、`BREAKPOINTS`、间距/圆角/运动令牌。禁止近似色与拍脑袋值——视觉稿与最终实现零色差，用户在稿上拍板的就是上线效果。
- 读取命中的 active Knowledge（组件既有结论、激活态驱动方式、生产禁令如「全文件禁 scrollIntoView」），列为**不可回退项**。
- 取现状基线：生产站点或本地截图，作为「改造前」对照。

### 2. 内容位 × 状态矩阵——布局之前先清点

列出所有内容承载位（题名/歌手/模式/音量/歌词/列表……），每个位标注三维：

- **长度可变性**：i18n 后文案长度是否固定？不确定 → 指定溢出策略（跑马灯徐展/省略+title/限宽/换行封顶/收纳进抽屉——任一语言宽度必须有界）。
- **交互态全集**：常态/展开/弹层/空态/加载/播放/暂停/拖拽——漏一个态就是返工一轮。
- **激活/显隐实现约束**：走行内样式或行内自定义属性（选择器与动态类驱动在生产上有规则删除竞态与属性翻转失灵两连败史，禁入）。

矩阵给用户过目后再画图。

### 3. 一稿多构——结构不同，不是皮不同

一次性给出 **3–4 个结构上互斥**的布局提案（例：三栏改良 / 对页书 / 竖排词卷 / 留白独奏），每个附：

- ASCII 构图 + 一句定位（最文人 / 密度最高 / 最空灵 / 风险最高）。
- 高保真实现：**单文件静态 HTML**，真 token、真字体、真组件 CSS，`?scene=` 参数切场景；本地静态服务 + 浏览器自动化截图供用户点选。

视觉稿技巧：动画用 `animation-play-state: paused` + 负 `animation-delay` 定格在可读帧；封面等内容用风格化占位并标注「示意」。

### 4. 迭代轮——用户选中后小步精修

在选中骨架上做**小步精修轮**，每轮只动 3–5 个**可指认**的细节（比例/字距/界格/氛围/新交互件），编号列清单后动手，逐态截图回报。用户否决的构图方向**立即归档留痕**（方向名 + 否决理由，进 brief 对比方案段），同一需求内不得复活；用户说「参考 X」= 提取 X 的交互模式而非视觉皮，用本项目设计语言转译。

### 5. 移植性自检——每轮自查，不留给 review

- **状态完备**：每个新交互件有 aria（`expanded`/`pressed`/`haspopup`）、键盘等价路径、`prefers-reduced-motion` 降级、外点/Esc 收起。
- **i18n 长度**：任一语言下宽度有界（拿 en/ja 最长文案脑内过一遍每个位）。
- **态驱动方式**：激活/显隐一律行内样式或行内自定义属性。
- **既有禁令不回退**：把第 1 步列的生产禁令逐条对验。

### 6. 定稿产出

交回 propose/用户三件套：① 视觉稿文件路径（可交互）② 各关键态截图 ③ **设计决策清单**——逐条编号，每条映射实现文件、词典 key 与守卫断言，propose 原样写入 brief 决策与任务。视觉稿路径随 brief 留档。

## 提词解码表

| 用户说 | 动作 |
|--------|------|
| 参考网易云 / 参考 X | 提取交互模式，本项目语言转译，不抄视觉 |
| 不喜欢这种布局 | 该方向归档留痕 + 追问否决维度（结构/密度/氛围） |
| 再优化 / 继续打磨 | 小步精修轮：3–5 个可指认改动，先列清单 |
| 差不多 / 可以了 | 收敛定稿，产三件套，回 propose |

## 硬规则

- 不做状态矩阵直接画图 = 返工，禁止。
- 视觉稿不用真 token = 用户拍板的是假效果，禁止。
- 单构多变冒充多构提案，禁止——结构互斥才算多构。
- 否决方向在原需求内复活，禁止。
- 每轮精修必须留档截图链（素坯 → 各轮 → 定稿），作为 brief 附件证据。
